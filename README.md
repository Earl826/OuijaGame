# Ouija Product Sceptic Simulation
**Technical Focus:** Real-time Multiplayer Synchronization & Semantic Logic

## Overview
A co-op multiplayer experience engineered in C# that simulates magnetic planchette logic and dynamic sceptic interactions. The project explores the intersection of real-time physics and psychological simulation.

## Key Technical Features
* **Real-time Synchronization:** Prototyping backend methods to handle low-latency "fooling" mechanics between multiple players.
* **Magnetic Physics Engine:** Simulating authentic magnetic planchette movement via C# physics logic.
* **Semantic Belief Metrics:** Designing semantic similarity algorithms to dynamically calculate "sceptic doubt" based on player input and planchette behavior.

## Current Development Phase
* **Active:** Core multiplayer state synchronization and physics logic.
* **Next Steps:** Refining belief-metric triggers and expanding "skeptic" AI responses.
